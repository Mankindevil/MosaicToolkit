Mosaic Toolkit 0.1.11 — Unity 遮罩检查工具
制作日期：2026-10-06

启动
双击 MosaicToolkit-0.1.11.exe。Windows 图形界面，无需命令行、Python 或 Node。
运行和构建依赖 Windows 自带/已启用的 .NET Framework 4.x。
输出默认保存在所选游戏目录下的 MosaicToolkit 文件夹；该游戏目录需要可写。

第一版范围
支持：BepInEx 5 / Mono，.NET 4，含 UnityEngine.CoreModule、System.Runtime.Serialization、System.Xml 的 Unity 游戏。
自动识别：Unity 版本、Mono/IL2CPP、x86/x64、BepInEx 主版本。
IL2CPP 目前只识别，不能生成或安装补丁。旧版 Unity/.NET 3.5 不在第一版范围内。
不自动下载、替换或升级加载器。不同时安装多个加载器。
本工具按目标游戏本机程序集生成插件；可构建不等于该游戏内已验证兼容。

首次使用
1. 关闭游戏。在程序中点击“选择游戏 EXE”，选择真正的游戏执行文件。
   例如选择游戏根目录中的 painRein.exe，不要选择 UnityCrashHandler。
2. 查看检测结果。未装 BepInEx 5 时，先安装与游戏匹配的加载器，再点“检测”。
3. 点击“安装扫描插件”。界面显示目标目录，确认后构建并写入 BepInEx\plugins\MosaicToolkit。
   新安装使用发现模式；已保存的规则会保留，但自动执行设为关闭。
   “操作前备份”默认关闭。开启后重装会保留旧插件；关闭时安装成功后清除旧插件暂存。
4. 点击“启动游戏”，或按平时方式从平台启动游戏。进入目标角色/服装/场景。
5. 程序显示“已连接”后，“候选对象”和“全部 Renderer”表会自动更新。

升级至 0.1.11
退出游戏和旧桌面工具，打开 MosaicToolkit-0.1.11.exe，选择游戏 EXE，再点击“安装扫描插件”。
本版增加切换窗口时的后台运行适配，并保留新版 Unity 编译修复；必须重新构建安装扫描插件才能生效。
规则保留，自动执行暂时关闭；重启游戏后点击“生成并启用默认规则”，之后换场景无需再点。
本版桌面和扫描插件均为 0.1.11。已有规则继续兼容；材质槽临时操作需要快照功能级别 4。

一键初始化默认规则
1. 进入目标场景，连接成功并完成首次扫描后，点击顶部“生成并启用默认规则”。
2. 所有材质槽均命中关键词：生成关闭整个 Renderer 的规则，并记录完整材质槽条件。
3. 只有部分材质槽命中：生成隐藏这些槽的规则，普通材质及 Renderer 保持原状态。
4. 单材质对象也允许按对象名推断；多材质对象仅有对象名命中、无法确定槽时跳过。
5. 默认规则采用准确对象名、组件类型、槽序号、材质名和 Shader 匹配。不是对效果用途的百分之百识别。
6. 点击后立即保存并启用规则，同时开启自动补充，保留已有规则并去重。已停用的重复规则不会被重新开启。
7. 自动跳转“保存的规则”，可查看动作、材质槽条件与启停状态。误匹配时选中规则点“启停选中规则”或“移除选中规则”。
8. “停止全部并恢复”停用自动执行和自动补充，恢复本工具接管的 Renderer 状态和材质引用；规则列表仍保留。
9. 新场景加载后和动态对象被扫描发现后，自动追加并启用新规则；关闭桌面工具后也继续。已停用或删除的规则不会自动恢复。
   在“保存的规则”取消“自动补充新场景规则”可停止学习，已有规则继续执行。“停用自动规则”同时停止执行和学习。
   自动补充复用现有扫描，不提高全场景扫描频率；总规则上限 2000 条。无新规则时不重复写文件。
10. 材质槽模式只替换目标 Renderer 的命中槽引用，不修改游戏资源或其他对象共用的原始材质。
    使用游戏可用的 UI/Default 创建一个不输出颜色、不写入深度的隐藏材质；若缺失或不支持，则日志提示跳过，不会退回关闭整个 Renderer。

列表使用
“全部 Renderer”显示已加载场景内的全部 Renderer，包含未激活对象，可按名称、组件、Shader、材质或路径筛选。
新增状态和组件下拉框，与文字筛选同时生效。“重置”清除筛选并恢复发现顺序。
状态：已启用、已关闭、持续关闭、隐藏材质槽、对象未激活、规则命中、规则未命中。
“已启用”指对象活动且 Renderer 启用、没有被本工具持续关闭或隐藏材质槽；不代表一定出现在相机内。
“已关闭”对应普通关闭状态；本工具保持关闭的对象单独归入“持续关闭”。
“对象未激活”包括同时已关闭的对象；规则命中/未命中独立于开关状态。隐藏材质槽可能保持 Renderer.enabled=true。
排序可选发现顺序、状态、对象名、组件、Shader、命中依据、路径，支持升序和降序；点击列标题可切换排序方向。
状态升序：已启用 → 已关闭 → 持续关闭 → 隐藏材质槽 → 对象未激活。同值维持发现顺序，避免反复跳动。
刷新保留筛选和排序，状态改变时重新判断；仍在列表中的选择和滚动锚点保留，被筛掉的选择取消，不会转移到邻行。
手动更改筛选或排序时回到结果顶部，后台刷新则保持滚动位置。
状态依据扫描快照，可能有扫描延迟。筛选和排序只在桌面处理，不增加游戏扫描频率。
已有行按会话内对象 ID 保持位置、选择和滚动状态；新对象追加，已消失对象移除。
短暂断连保留旧列表供查看，暂停向游戏发操作；新游戏会话清除旧选择。
仅刷新当前页签，切换页签时使用最新已接收快照。

手动选择材质槽（0.1.9 新增）
1. 在“全部 Renderer”或“候选对象”只选一个对象，点击“材质详情”，也可双击对象行。
2. 详情是独立非模态窗口，可继续操作主列表和游戏。窗口固定绑定打开时的对象，不跟随主列表选择变化。
3. 勾选槽编号后点击“临时隐藏所选槽”，支持多选。重复材质名仍按槽编号区分，例如槽 0 和槽 2 可分开隐藏。
4. “恢复所选槽”只恢复所勾选槽的临时隐藏。如果该槽仍受自动规则控制，会提示先停用对应规则。
5. 整个 Renderer 已关闭时，临时隐藏按钮禁用；先从主列表恢复整个 Renderer，或停用关闭它的规则，再观察单槽效果。
6. “保存为规则”按每个勾选槽保存一条完整路径 + 对象名 + 组件类型 + 槽编号 + 材质名 + Shader 规则，并跳过重复项。
   保存不会开启全局自动执行；已开启自动执行时，新启用规则也会参与执行。已有停用的同一规则不会自动重新启用。
7. 窗口刷新保留未变化槽的勾选；槽内容改变时清除该槽勾选。空材质槽不可操作。
8. 连接过期、对象不在快照中或游戏会话改变时，保留详情但禁用操作；重新定位对象后再打开。
9. 关闭详情窗口或桌面工具保留临时效果。“停止全部并恢复”撤销临时控制；退出游戏后临时操作失效。
10. 操作后以游戏确认及“已隐藏”状态为准。缺少可用隐藏材质或校验失败时会报错，不会关闭整个 Renderer 作为替代。
    按槽隐藏会隐藏该槽绘制的全部内容，不能分离同一槽内已经合并的背景与遮罩；同路径同类型对象也可能匹配保存的规则。

扫描与验证
- 默认关键词：mosaic、モザ、censor。可用逗号分隔新增关键词，并点“应用”。
- 匹配对象自身名称、材质名、Shader 名；包含未激活的已加载场景对象。
- 候选只是一条线索：mosaic 装饰材质、主体共享 Shader 等可能误命中。
- 选中候选（Ctrl/Shift 可多选），点“临时关闭选中”，观察游戏画面。
- 点“恢复选中”恢复本工具接管前的 Renderer.enabled。原本 false 的对象仍为 false。
- 临时关闭在本次游戏会话内保持；仅关闭桌面窗口不会恢复，需点恢复按钮或退出游戏。
- 自动规则控制的对象，需先“停用自动规则”再恢复；“停止全部并恢复”会停用规则并恢复临时控制。
- 如果已有旧版 PainReinMosaicOff 或其他类似补丁在运行，它们可能再次关闭对象，影响恢复验证。
  请退出游戏后自行将旧补丁移出 plugins。新程序不会删除其他插件。

保存与导出
1. 确认临时关闭只影响目标遮罩后，点击“选中项加入规则”。
2. 在“保存的规则”页检查。可识别的遮罩采用上述默认分类；其他人工选中对象沿用准确对象名 + 组件类型 + Shader 的 Renderer 规则。
   默认不限层级路径，便于同名的不同角色/服装实例复用；同名同类型同 Shader 都会匹配。
   多材质对象优先选名称含关键词的 Shader，否则选择首个已知 Shader。
3. “启用保存的规则”让当前游戏持续执行，切换场景或换装后也会再次发现并关闭匹配项。
4. “导出自动补丁 ZIP”将规则设为自动执行，生成 BepInEx 插件和配置包，保存在 游戏目录\MosaicToolkit\output。
   导出不会自动安装，也不改变当前游戏的自动执行开关。
5. 将 ZIP 内 BepInEx 文件夹合并到对应游戏根目录。安装需退出游戏。
   安装导出的包后无需一直打开桌面程序、RUE 或 CUE，但扫描插件需保留。

规则保存、备份与预设
- 游戏目录\MosaicToolkit\profile.json 保存当前规则副本，自动补充时也更新。
- 插件运行时读取 BepInEx\plugins\MosaicToolkit\profile.json。请通过界面导入/编辑规则，避免手动改错副本。
- “导出规则 JSON”的默认目录为 游戏目录\MosaicToolkit，也可以自行选择位置。
- “操作前备份”位于“保存的规则”页，默认关闭，按游戏保存偏好。开启后在修改规则、自动追加、更新或卸载插件前保留旧内容。
- 备份开启时保存到 游戏目录\MosaicToolkit\backups；关闭后不生成新的备份，已有历史备份保留。
- 关闭备份不影响安装失败时的临时回滚；安装成功后清除旧插件暂存。
- “导入规则 JSON”替换当前列表，并将自动执行和自动补充关闭，保留本游戏的备份开关设置。
- 旧版工具 profiles 目录可作为读取回退，保存后写入新的游戏目录；历史文件不会自动删除。
- presets\PainRein-0.103.json 根据用户已验证的对象名及 Shader 提供示例规则，默认关闭自动执行。
- JSON 的 path 可填写候选表显示的完整路径以进一步限制；空字符串表示不限路径。
- “生成并启用默认规则”会按当前关键词生成规则并启用，支持单项停用和停止全部恢复。

卸载
退出游戏后点击“卸载本工具插件”。默认删除带本工具所有权标记的插件目录，不保留备份。
开启“操作前备份”时，将该目录移到 游戏目录\MosaicToolkit\backups。保留规则、加载器、RUE 和其他插件。
备份目录在 plugins 外，不会被 BepInEx 自动加载。
手动卸载也可在退出游戏后，将 BepInEx\plugins\MosaicToolkit 整个文件夹移出 plugins。

日志与连接
- 游戏日志：BepInEx\LogOutput.log；按钮“打开游戏日志”可直接打开。
- 插件启动应出现 Mosaic Toolkit Scanner 0.1.10 ready。
- IPC 文件：BepInEx\plugins\MosaicToolkit\session\snapshot.json 和 command.json。
- 桌面程序核对进程路径、会话 ID、快照时间；重启后的旧命令不会生效。
- 游戏最小化/后台停止更新或正在加载时，连接可能显示过期，回到游戏等待更新。
- 操作记录显示“游戏确认”才代表收到插件回复。它不能替代画面验证。
- 日志显示插件加载但没有快照时，可检查 BepInEx.cfg 的 HideManagerGameObject。
  某些游戏需退出后改为 true 再重启；程序不会擅自修改该配置。

性能与限制
已缓存的目标在 LateUpdate 和 URP 相机开始渲染时保持关闭。
常规发现扫描每 5 秒启动一次；场景加载、规则变化或点击“重新扫描”会提前启动。
获取 Renderer 引用仍由 Unity 主线程完成；随后分帧读取元数据，每帧最多 32 个对象，并在约 2 毫秒预算到达后让出。
单次 Unity API 调用无法中途打断，因此该预算不是每帧绝对耗时上限。
扫描只读 sharedMaterials；Renderer 开关每帧只遍历受控制对象，材质槽最多每 0.25 秒检查一次。
隐藏材质全局复用一个工具自建实例，不为每个对象复制原材质。扫描展示被替换槽的原始信息，避免规则失效。
完整快照常规每 2 秒更新，扫描完成或命令执行时可提前；JSON 编码与磁盘写入在后台执行，最多一个任务，避免积压。
桌面端后台解析有变化的快照，不反复解析相同文件；IPC 读取允许原子替换，以减少文件占用冲突。
桌面关闭约 6 秒后停止完整快照传输；已启用规则及临时控制继续生效。没有桌面、规则和临时目标时停止扫描。
新对象发现可能延迟 5 秒加上分帧扫描所需时间；普通对象状态随扫描更新，受控制对象持续检查。
新生成对象在下次扫描前可能短暂显示。关键词改动、场景变动也需一次扫描。
快照最多显示前 1500 个候选；超过时请缩小关键词。
全部 Renderer 最多传输前 10000 项，超出时界面会提示。
支持 Renderer.enabled 和材质槽引用替换；不控制 GameObject.Active，不销毁组件，不修改原始 Shader 或贴图。
人工“临时关闭选中”仍关闭整个 Renderer；混合对象建议使用生成的“隐藏材质槽”规则。
UI Image/RawImage、相机后处理，以及原图自带的马赛克不在 Renderer 扫描范围。
渲染管线或游戏脚本在其他时点改回状态时，下次执行检查会再次关闭；不承诺零闪现。

0.1.11 后台运行适配
“连接工具时允许游戏后台运行”位于游戏检测信息下方，默认开启，按游戏保存。
工具心跳有效时，插件在 Unity 主线程临时设置 Application.runInBackground=true；切到工具后继续扫描和处理默认规则。
关闭开关、关闭工具后约 6 秒、禁用或销毁插件时恢复接管前的设置。游戏本来就允许后台运行的，恢复后仍为开启。
不连接工具、只运行导出的补丁时，不强制后台运行。规则执行和后台运行开关彼此独立。
如果游戏在连接工具前已经暂停，请切回游戏几秒，再切回工具。游戏自身额外实现的暂停逻辑需实机验证。
状态栏区分“游戏未运行或退出”“快照属于其他进程”和“游戏仍运行但扫描数据过期”；旧数据仍仅供查看，不能直接执行操作。
已验证恢复逻辑、配置兼容、界面和三款游戏程序集编译；尚未进行实机切窗测试。
